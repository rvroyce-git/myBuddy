    How a report comes together

    1. 📰

      Public sources

      RSS feeds, Hacker News, arXiv, Hugging Face, GitHub and CISA. No logins, no paid APIs.

    2. 🖥️

      MyBuddy on Oracle

      A small Python app on a free cloud server collects, removes duplicates and keeps what's new.

    3. ✍️

      Cited AI summary

      A free Groq model writes a short summary. Anything it can't link to a source gets dropped.

    4. 💬

      Your Telegram

      The report lands in a private chat with your own bot, ready with your first cup of tea.

    Plain and honest

    Where your data goes

    🏡 Stays on your server

    • The news it collects and its history
    • Your topics and settings
    • Your API keys, in a private file only the app's user can read

    ✉️ Steps outside

    • Each prompt goes to the AI provider. Free providers may log prompts, so MyBuddy only ever sends public news.
    • Finished reports go to your own private Telegram chat and this public page.

    The honest trade-off: free models are weaker than paid ones. Summaries are simpler, and now and then a day comes out thin. That's the price of $0, and the links are always there to read the original.

    About an evening's work

    Run your own MyBuddy

    1. Get a free server

      Create an Oracle Cloud Always Free VM. The smallest one is plenty.

    2. Grab two free keys

      A Groq API key for the AI, and a Telegram bot token from @BotFather.

    3. Install and check

      Clone the repo, install it with Python, and let mybuddy check confirm everything is wired up.

    4. Let it run

      Start mybuddy serve as a service and forget about it. Tomorrow's news will find you.

    # on your Oracle VM
git clone https://github.com/rvroyce-git/myBuddy.git mybuddy
cd mybuddy && python3 -m venv .venv
. .venv/bin/activate && pip install -e .

# keys stay in a private env file (mode 600)
nano ~/.config/mybuddy/env   # GROQ_API_KEY=…

mybuddy check
mybuddy run all --dry-run
mybuddy serve

    Good questions

    FAQ

    Is it really free?

    Yes. Oracle's Always Free tier gives you a small server at no cost, Groq has a free tier for its models, Telegram bots are free, and every news source is public. Nothing in MyBuddy needs a credit card to run day to day.

    Can the AI make things up?

    It's asked to tie every claim to one of the collected links, and anything it can't cite is thrown away. Links always come from the collected news, never from the model. If the AI fails completely, you still get a plain list of the day's items.

    Why Telegram?

    A Telegram bot is free, takes two minutes to create, and works on every phone and laptop. Your reports sit in one private chat you can search later, and urgent security alerts arrive as a normal notification. (Discord webhooks work too, if you prefer.)

    Can I change the topics or the times?

    Yes. Topics, sources and times live in one small settings file. Add a feed, move a time, or turn a topic off.

    What's this page, then?

    A simple public window onto the latest reports. MyBuddy writes a small data file after each run and this page reads it. No tracking, no accounts.
