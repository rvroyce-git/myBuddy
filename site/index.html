    How it works

    1. From early morning daily, it checks 37 public feeds: OpenAI, Google AI, Hacker News, GitHub, arXiv, Hugging Face, CISA and more. Already-sent news is skipped.
    2. Groq AI writes a one-line headline and a two-sentence summary. Every link comes from the original source, never the AI.
    3. Each report arrives as a private message on your phone. Actively exploited security bugs are flagged within the hour.
    4. A minute later this page refreshes on GitHub Pages — all seven topics, free and public.

    What stays, what leaves

    Stays on our server

    Oracle Cloud · free tier

    • Saved reports and what’s already been sent
    • Settings, plus API keys in a private file
    • Subscriber chat IDs and chosen topics — nothing else

    Leaves the server

    Public news only

    • Public news text to Groq AI to summarise
    • Finished summary to subscribers’ phones, as private alerts
    • Same summary to this public page

    Nothing personal is sent. The AI provider may log prompts — run a local model if nothing should leave.
